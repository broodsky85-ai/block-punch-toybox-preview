# 블록펀치 TOYBOX 그래픽 체험판

블록펀치 게임의 규칙을 그대로 유지하고, 장난감 같은 입체 UI를 추가한 공개 웹 체험판입니다.

- 30조각 기록전 → 블록 선택 → 보드에서 배치 → 쌓기/뚫기 모드 전환
- 제목과 플레이 화면의 **원본 비교** 버튼으로 같은 게임 상태에서 그래픽 차이 확인
- 기존 Play Store 정식판, Android APK, 계정/랭킹/광고 운영 설정은 변경하지 않음
- 체험판 기록은 브라우저 저장 공간에만 남으며, 정식 앱 기록과 분리됩니다.
- PC와 모바일 브라우저에서 플레이 가능합니다.

이 웹 링크는 시연 목적으로 공개된 별도의 GitHub Pages 정적 사이트입니다.
